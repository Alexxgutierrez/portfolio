## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Alexxgutierrez/portfolio.git
```

### 2. Open the Project Folder

```bash
cd portfolio
```

### 3. Run the Website

Open:

```bash
index.html
```

in your browser.

---

## 🌐 Deploy to GitHub Pages

Run the deployer script:

```bash
python deploy.py
```

After deployment:

1. Go to your GitHub repository
2. Open **Settings**
3. Click **Pages**
4. Set:

```text
Source → Deploy from branch
Branch → main
Folder → / (root)
```

Your website will be available at:

```text
https://Alexxgutierrez.github.io/portfolio/
```
